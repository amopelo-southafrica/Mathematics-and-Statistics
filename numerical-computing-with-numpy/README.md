# NumPy Arrays and Matrix Indexing

## What this project is about

Explore how to reshape a sequence of numbers into a three-dimensional array and extract, reverse, and join selected sections of that array.

## What I implemented

The source code is in `numpy_task.py`. The implementation uses NumPy, multidimensional arrays, slicing, advanced indexing, reshaping and concatenation.

## How to run

Install NumPy (`pip install numpy`), then run `python numpy_task.py`.

## Notes

The script prints selected matrices and slices to show the result of each operation.
