# Wine Varietal Exploration

## What I explored

I inspected wine data and selected Cabernet Sauvignon, Pinot Noir and Chardonnay entries for closer comparison.

## How I approached it

I used pandas, matplotlib, seaborn in the [Jupyter notebook](wine_varietal_analysis.ipynb) to complete the analysis. The notebook contains my original code and explanations.

## How to run

Install Jupyter and pandas, matplotlib, seaborn, place `wine.csv` in the notebook's directory and execute the cells.
