# Polynomial

## What this project is about

An interactive Python calculator for differentiating a single polynomial term and finding its gradient at a chosen x-coordinate.

## What I implemented

The program asks for a coefficient, a power and an x-value. It applies the polynomial power rule, then substitutes the x-value to calculate the gradient at that point.

**Methods:** Python, polynomial differentiation, the power rule, user input and numerical substitution.

## How to run

Run `python polynominal.py` and enter the coefficient, power and x-coordinate when prompted. The filename retains its original spelling from the submission.

**Source:** HyperionDev, M09T03 – Calculus Fundamentals.
