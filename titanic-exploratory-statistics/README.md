# Titanic Survival: Exploratory Statistics

## What I explored

I explored the Titanic passenger data with descriptive statistics and charts to compare recorded survival outcomes by passenger characteristics.

## How I approached it

I used pandas, numpy, matplotlib, seaborn in the [Jupyter notebook](titanic_eda.ipynb) to complete the analysis. The notebook contains my original code and explanations.

## How to run

Install Jupyter and pandas, numpy, matplotlib, seaborn, place `Titanic.csv` in the notebook's directory and execute the cells.

## Notes

The charts show associations in the passenger records, not causal effects. The dataset is not packaged in this repository. Source: my HyperionDev submission (M08T08).
