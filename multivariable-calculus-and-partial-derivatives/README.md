# Multivariable Calculus with SymPy

## What this project is about

Calculate the partial derivatives and gradient vector of a function in two variables, illustrating how multivariable differentiation can be automated symbolically.

## What I implemented

The source code is in `multivaribale.py`. The implementation uses SymPy, symbolic differentiation, partial derivatives, gradient vectors.

## How to run

Install SymPy (`pip install sympy`), then run `python multivaribale.py`.

## Notes

The worked expression is `f(x, y) = x² + y²`.
