# Pandas Data Selection

## Overview

I used pandas to inspect credit-record data, select rows and columns by label or position, filter records and sort by education.

## Implementation

I wrote the analysis in [pandas_data_selection.ipynb](pandas_data_selection.ipynb) using pandas. The notebook contains the data preparation, calculations and/or charts that support the analysis.

## Running the project

Install pandas and Jupyter. Place `balance.txt` in the working directory and execute the notebook cells in order.

The source dataset is not included with this project; some results require the specified input file. Source: my HyperionDev submission (M08T03).
