# Investment and Bond Calculators

## What this project is about

Compare the outcome of simple versus compound investment interest, or estimate a monthly mortgage payment from the principal, interest rate and term.

## What I implemented

The source code is in `finance_calculators.py`. The implementation uses Python `math`, financial mathematics, interest formulas, annuity repayment calculations, terminal input.

## How to run

`python finance_calculators.py`

## Notes

The investment choice currently accepts the single words `simple` and `compound`. Mortgage repayment assumes a nonzero interest rate.
