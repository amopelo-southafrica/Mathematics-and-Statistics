# Calculus

## What this project is about

A numerical calculus example connecting derivatives to the optimization of a simple linear model. The Python script defines a prediction function, a mean-squared-error objective and its analytical derivative, then implements a gradient-descent parameter update.

## What I implemented

- A linear model that predicts values from input data and a parameter.
- Mean squared error to measure prediction differences.
- An analytical derivative of the error with respect to the model parameter.
- A gradient-descent update using a specified learning rate.

**Methods:** Python, NumPy, differential calculus, mean squared error, gradient descent.

## How to run

Install NumPy with `pip install numpy` and open `calculus.py` in Python or an editor. The script defines the functions and example arrays; it does not execute an iterative training loop or print a final parameter by itself.
