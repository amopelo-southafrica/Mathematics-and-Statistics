# Diabetes Progression Regression

## What I explored

I used multiple linear regression, a train/test split and feature scaling to model recorded diabetes progression and compare actual and predicted values.

## How I approached it

I used pandas, numpy, matplotlib, seaborn, scikit-learn in the [Jupyter notebook](diabetes_multiple_regression.ipynb) to complete the analysis. The notebook contains my original code and explanations.

## How to run

Install Jupyter and pandas, numpy, matplotlib, seaborn, scikit-learn, place `diabetes_dirty.csv` in the notebook's directory and execute the cells.

The notebook is a statistical modelling exercise, not a medical service. The dataset is not packaged in this repository. Source: my HyperionDev submission (M09T02).
