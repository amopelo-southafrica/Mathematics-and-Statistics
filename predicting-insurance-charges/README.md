# Insurance Cost Linear Regression

## What I explored

I used simple linear regression to model the relationship between age and insurance charges, and plotted the fitted line.

## How I approached it

I used pandas, matplotlib, seaborn, scikit-learn in the [Jupyter notebook](insurance_cost_regression.ipynb) to complete the analysis. The notebook contains my original code and explanations.

## How to run

Install Jupyter and pandas, matplotlib, seaborn, scikit-learn, place `insurance.csv` in the notebook's directory and execute the cells.

## Notes

The notebook trains and plots on the same records; it does not report out-of-sample accuracy. The dataset is not packaged in this repository. Source: my HyperionDev submission (M09T02).
