# Diabetes Statistical Visualisation

## Overview

I examined diabetes-outcome distributions and compared age, glucose and BMI measurements with summary statistics and charts.

## Implementation

I wrote the analysis in [diabetes_visualisation.ipynb](diabetes_visualisation.ipynb) using pandas, matplotlib, seaborn. The notebook contains the data preparation, calculations and/or charts that support the analysis.

## Running the project

Install pandas, matplotlib, seaborn and Jupyter. Place `diabetes(1).csv` in the working directory and execute the notebook cells in order.

The source dataset is not included with this project; some results require the specified input file. Source: my HyperionDev submission (M08T09).
