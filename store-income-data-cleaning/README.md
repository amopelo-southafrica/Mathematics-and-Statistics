# Store Income Data Cleaning

## Overview

I cleaned inconsistent country names, converted measurement dates and calculated the age of store income records.

## Implementation

I wrote the analysis in [store_income_cleaning.ipynb](store_income_cleaning.ipynb) using pandas. The notebook contains the data preparation, calculations and/or charts that support the analysis.

## Running the project

Install pandas and Jupyter. Place `store_income_data_task.csv` in the working directory and execute the notebook cells in order.

The source dataset is not included with this project; some results require the specified input file. Source: my HyperionDev submission (M08T07).
