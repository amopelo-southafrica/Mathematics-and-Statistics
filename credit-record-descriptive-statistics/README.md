# Descriptive Credit Statistics

## Overview

I calculated grouped income and balances, minimum and maximum income, card totals and category counts in credit records.

## Implementation

I wrote the analysis in [credit_statistics.ipynb](credit_statistics.ipynb) using pandas. The notebook contains the data preparation, calculations and/or charts that support the analysis.

## Running the project

Install pandas and Jupyter. Place `balance.txt` in the working directory and execute the notebook cells in order.

The source dataset is not included with this project; some results require the specified input file. Source: my HyperionDev submission (M08T03).
