# Descriptive Credit Statistics

## Overview

This project uses pandas to investigate **400 credit-related observations** in the included `balance.txt` file. The notebook calculates average recorded income by ethnicity, balance by marital status, minimum and maximum recorded income, the total number of cards and category counts.

The file is **whitespace-delimited**, not comma-delimited. Its categorical values may be enclosed in quotation marks (for example, `"African American"`). The corrected notebook uses `pd.read_csv("balance.txt", sep=r"\s+")` and checks for 400 rows and 11 columns.

## Verified descriptive indicators

| Measure | Result |
|:--|--:|
| Records / columns | 400 / 11 |
| Income: minimum and maximum | 10.354 / 186.634 |
| Overall recorded income mean | 45.219 |
| Recorded card count (sum of `Cards`) | 1,183 |
| Female / Male records | 207 / 193 |
| Mean `Balance`: married (`Yes`) | 13.388 |
| Mean `Balance`: not married (`No`) | 13.494 |

These numbers were independently calculated from the uploaded source file. They are descriptive, not causal estimates. The dataset's sampling period, population and monetary/transform units are **not documented**, so the `Balance` values must not be presented as verified currency amounts.

## Running the project

Install Python, pandas and Jupyter. Keep `balance.txt` in the same folder as the notebook, then run the notebook cells from top to bottom.

If loading manually:

```python
import pandas as pd
df = pd.read_csv("balance.txt", sep=r"\s+")
assert df.shape == (400, 11)
```
